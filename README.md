# Series Tracker

แอปแท็กซีรีย์ที่กำลังดู — ดูถึงตอนไหนแล้ว, ซีซันอะไร, สถานะอะไร (กำลังดู / ดูจบแล้ว / พักไว้ / อยากดู)
สร้างด้วย Next.js (App Router) เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์ ไม่ต้องมีฐานข้อมูล ไม่ต้องตั้งค่า env

## รันบนเครื่องตัวเอง

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## Deploy ขึ้น Vercel

วิธีที่ง่ายที่สุด (ไม่ต้องใช้ Git):

```bash
npm install -g vercel
vercel
```

ตอบคำถามที่ CLI ถามไปเรื่อย ๆ (ใช้ค่า default ได้เลย) แล้วมันจะ build และ deploy ให้อัตโนมัติ ได้ลิงก์กลับมาใช้งานได้ทันที

หรือถ้าจะ deploy ผ่านเว็บ:
1. Push โปรเจกต์นี้ขึ้น GitHub repo
2. ไปที่ https://vercel.com/new แล้วเลือก import repo นั้น
3. Framework Preset จะตรวจเจอเป็น "Next.js" อัตโนมัติ — กด Deploy ได้เลย ไม่ต้องตั้งค่าอะไรเพิ่ม

## หมายเหตุ

- ข้อมูลซีรีย์เก็บอยู่ใน localStorage ของเบราว์เซอร์เครื่องนั้น ๆ เท่านั้น (คนละเครื่อง/browser จะไม่เห็นข้อมูลเดียวกัน) ถ้าอยากให้ sync ข้ามอุปกรณ์ ต้องต่อฐานข้อมูล (เช่น Vercel Postgres, Supabase) เพิ่มทีหลังได้
- กด "+ เพิ่มซีรีย์" เพื่อเพิ่มเรื่องใหม่, กดปุ่ม +/− เพื่อขยับตอนที่ดู, กด "แก้ไข" เพื่อเปลี่ยนซีซัน/สถานะ/ลบ
